Thesis in one sentence

The scaffolding framework around an LLM matters more than the LLM itself — two different LLMs in the same agent framework behave almost identically at the procedural level, while two different frameworks using the same LLM diverge substantially.

Headline findings (8 shipped, 4 validated)

Shipped and in figures

Scaffold > backbone. Backbone probe F1 = 0.83; within-scaffold backbone swap barely changes procedure (JSD 0.11–0.20). Cross-scaffold JSD 0.54–0.78. Paradigm exception: extended-thinking Claude sits at 0.54–0.63 even within SWE-agent — paradigm shift breaks scaffold homogenization.
Three-regime JSD structure. Agentless ~1.0 vs all (deterministic pipeline); within-SWE-agent 0.11–0.20; cross-scaffold 0.54–0.78.
Per-agent fingerprint. Four scalars bucket cleanly by scaffold: entropy 0–6 bits, repertoire@90% 1–49, compression 0.08–0.57. Agentless is a degenerate case (single pipeline = 0 entropy, 1 action type).
Cost × resolve efficiency. Within-scaffold backbone choice creates 4× spread in cost/resolved. Steps ≠ efficiency: Claude-3.5 takes more steps than GPT-4 but is 2× cheaper per resolved.
Type B failure dominates. Post-localization failure (agent found the right file, still failed to fix) accounts for 57% (Claude-3) to 91% (Claude-3.7-thinking) of all failures. Not a search problem — a repair problem.
Stuck-edit-loop signature. EDIT_SRC_PY +0.053 / SUBMIT −0.063 in long Type B failures across 7 scaffolds. Generalizable detector.

New (May 2026 session)

Controlled evaluations — within-agent (new). Low edit retry rate predicts success for GPT-4o (+16pp, p=0.004). Search-before-edit shows consistent +8–12pp trend across agents (underpowered individually). Repro step reverses direction: negative for old Claude models, positive for extended-thinking ones — suggesting the repro strategy only works when the agent is capable of executing it.
Controlled evaluations — matched-task null (new). After controlling for task difficulty (same instance, different agents), all procedural effects collapse to near-zero (largest: Δ+0.030, p=0.19). Task difficulty dominates, consistent with η²=0.56 from prior work. Procedural approach is a fingerprint, not a causal lever — within the observed corpus.
